# Social Receipt Content Tracking Register

Use the platform-specific link for the same video. Keep the campaign, content ID, hook, and experiment ID consistent across platforms.

## Link structure

```
https://socialreceipt.netlify.app/?utm_source=PLATFORM&utm_medium=organic&utm_campaign=CAMPAIGN&utm_content=CONTENT_ID&utm_term=HOOK_ID&utm_experiment=EXPERIMENT_ID
```

The app preserves first-touch attribution and records latest non-direct attribution. Never include private message text, names, or email addresses in tracking values.

## How to use

- YouTube: place the YouTube link in the description and pinned comment.
- TikTok: use the TikTok version in the bio link while promoting the video.
- Instagram: use the Instagram version in the bio link and story link.
- Facebook: place the Facebook version in the caption or pinned comment.
- Do not reuse one platform link for another platform.
- Do not change the content ID after posting.
