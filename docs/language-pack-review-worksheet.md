# Spanish and French Phrase Pack Review

## Purpose

Please review the short messages below as a fluent speaker familiar with everyday texting in the United States. This is a language and tone review, not a test of you. We want to know whether each message sounds natural and what a recipient might reasonably hear from the wording alone.

Please do not infer a diagnosis or decide what the sender secretly intends. If context would change your reading, say what context matters.

For each message, reply with:

1. **Naturalness:** natural / understandable but awkward / unnatural
2. **Likely first read:** ordinary or caring / clear boundary / frustrated / blaming or guilt-inducing / sarcastic or dismissive / threatening / unclear / other
3. **Context that could change the read**
4. **A more natural wording**, only if needed, preserving the apparent meaning
5. **Dialect or regional note**, if relevant

Please flag when a phrase varies substantially by country, region, age, or relationship. One person’s reading is useful feedback, not a universal language rule.
